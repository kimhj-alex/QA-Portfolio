No Date Jump Navigation on Desktop; Mobile Search Limited to Two-Year Window

Low Severity Web · Mobile Navigation Feature Parity
ID BR-008
Severity Low
Priority Low
Status Found Apr 2026
Platform Google Calendar
Environment macOS · Brave · calendar.google.com · iPhone · iOS · Google Calendar app
Feature Area Date Navigation · Search · Mobile
Tester Hyeji Kim (Alex)
Date 2026

Summary

Google Calendar lacks a direct date jump feature on both desktop and mobile. On desktop, navigating to a specific past or future date requires switching to Year view and clicking through months manually — a multi-step workaround with no date input field or dropdown anywhere in the interface. On mobile, Year view is not available at all, making manual date navigation even more tedious. The mobile search function compounds this issue by enforcing a hard two-year search window: results display only entries after a date approximately two years prior to the current date, with a notice at the top reading "Only entries after [date] are shown here." Past events outside this window — such as medical appointments from 2022 — are completely inaccessible from the mobile app and can only be retrieved by switching to desktop. No option to extend the search range is provided on mobile.

Steps to Reproduce — Desktop Navigation

  1. 1.Open calendar.google.com and attempt to navigate to a specific date in the distant past or future
  2. 2.Observe: no date input field, jump-to-date dropdown, or search-by-date option exists
  3. 3.Switch to Year view — click the left arrow repeatedly to navigate to the target year
  4. 4.Scroll to the target month and click the target date
  5. 5.Observe: Day view for the selected date loads after a brief loading state

Steps to Reproduce — Mobile Search Cutoff

  1. 1.Open the Google Calendar app on iOS
  2. 2.Tap the search icon and search for a recurring event or appointment (e.g. "dentist")
  3. 3.Observe: results load with a notice at the top — "Only entries after [date ~2 years ago] are shown here"
  4. 4.Scroll through all results — confirm events older than the cutoff date are not shown
  5. 5.Attempt to find an option to extend the search range — observe no such option exists
  6. 6.Repeat the same search on desktop — observe all historical events appear with no date restriction

Expected Result

Google Calendar provides a direct date jump input on desktop allowing users to navigate to any date without manual arrow navigation. Mobile search returns all matching events regardless of age, or provides an option to expand the search range beyond the default two-year window.

Actual Result

No date jump input exists on desktop or mobile. The only navigation method is manual arrow clicking, with Year view as the fastest available workaround on desktop only. Mobile search silently limits results to approximately the past two years with no option to extend the range, making historical events inaccessible from the mobile app entirely.

Screenshot

Mobile search results showing the two-year cutoff notice

Two Separate Issues

1 — No Date Jump Navigation

Neither desktop nor mobile provides a direct way to navigate to a specific date. Desktop requires switching to Year view and clicking through manually. Mobile doesn't offer Year view at all.

2 — Mobile Search Hard Cutoff

Mobile search enforces a ~2 year window with no way to extend it. Events outside this range — medical records, past appointments, historical entries — are completely inaccessible from mobile.

Severity Rationale

Why Low

Google Calendar is primarily a forward-looking scheduling tool and most users rarely need to navigate far into the past. However, the mobile search cutoff crosses from inconvenience into a genuine data accessibility issue for users who rely on their calendar as a historical record of appointments.

Suggested Fix

Add a "Jump to date" input field accessible from the mini calendar on desktop. On mobile, add an option in search to expand results beyond the default window, or remove the hard cutoff entirely and load results progressively.
