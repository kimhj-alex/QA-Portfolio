Gmail

Account Delegation Feature Absent from Mobile App with No Guidance

Medium Severity Mobile · iOS Feature Parity Missing Guidance
ID BR-003
Severity Medium
Priority Medium
Status Open
Platform Gmail
Environment iPhone · iOS · Gmail app · November 2025
Feature Area Account Settings · Delegation
Tester Hyeji Kim (Alex)
Date 2025–2026

Summary

Gmail's account delegation feature — which allows an account owner to grant another person access to their inbox — is entirely absent from the Gmail mobile app. The setting does not appear anywhere in the app's account settings, and no message, tooltip, or prompt indicates that the feature exists or that it must be configured on desktop. Google's official support documentation discloses that initial delegation setup requires a computer, but does not communicate this limitation within the app itself. Once delegation is set up on desktop, the delegated account is also inaccessible from the Gmail mobile app — access is only possible by opening gmail.com in a mobile browser and requesting the desktop site, a workaround with no in-app guidance. The feature gap is particularly disruptive for administrative users who rely on delegation for inbox management and expect a consistent experience across devices.

Steps to Reproduce

  1. 1.Open the Gmail app on iOS
  2. 2.Navigate to Settings → select an account
  3. 3.Search for a delegation, account access, or delegate setting
  4. 4.Observe: no delegation option exists anywhere in the app settings
  5. 5.Search within the app for help or guidance on delegation — observe no results or explanation
  6. 6.Open gmail.com in a mobile browser — observe delegation is also not accessible in the default mobile view
  7. 7.Request desktop site in the mobile browser — observe delegation settings now appear
  8. 8.Note: this workaround is not documented or suggested anywhere within the Gmail app

Expected Result

The Gmail mobile app either supports account delegation directly, or clearly communicates within the app that delegation must be configured on desktop — with a direct link or instruction to do so. If a delegated account cannot be accessed from mobile, the app explains this limitation and provides the desktop site workaround.

Actual Result

The delegation feature is entirely absent from the Gmail mobile app with no explanation. No in-app message, prompt, or help content points users to desktop. Access to a delegated account from mobile is only possible by manually requesting the desktop site in a mobile browser — a workaround discoverable only through external research.

Severity Rationale

Why Medium

Delegation is a feature primarily used by administrative and professional users managing shared inboxes. Its complete absence from mobile — with no guidance — forces users onto desktop for a workflow that should be device-agnostic. The issue is a feature parity and discoverability failure, not a functional break of existing functionality.

Workaround

Not Documented In-App

Opening gmail.com in a mobile browser and selecting Request Desktop Site provides access to delegation settings. This workaround is not mentioned anywhere within the Gmail app or its in-app help content.

Status Note

Partial Rollout

As of 2026, Google has reportedly begun rolling out mobile delegation support, but availability is limited and unconfirmed. The finding reflects the experience as of November 2025, when no mobile access existed. In-app communication of this limitation remains absent regardless of rollout status.

Suggested Fix

Add a visible placeholder in the Gmail app's account settings where the delegation option would appear, with a message explaining that delegation must be configured on desktop and linking to the relevant support page. Until full mobile parity is achieved, in-app guidance is the minimum viable fix.
