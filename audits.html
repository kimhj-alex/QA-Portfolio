Methodology

"Structured sessions of real use — not scripted tests on demo environments."

Each audit began as ordinary use of a platform I was actively working with. When friction appeared, I documented it — steps to reproduce, expected vs actual behavior, severity rationale, and suggested fixes. The Shoebox Planner audit added a checklist and cross-device regression layer, testing all core features on desktop first, then repeating on iPad to surface touch-specific regressions.
